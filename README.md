# Server Manager

**Server Manager** — панель управления, предназначенная для запуска и управления различными проектами на сервере. С её помощью можно работать с разными типами проектов, включая Minecraft-серверы, Node.js-приложения и другие исполняемые файлы.

## 🚀 Установка и запуск

### 1. Установите Node.js

Скачайте и установите Node.js с официального сайта:

[https://nodejs.org/](https://nodejs.org/)

### 2. Скачайте проект

Скачайте репозиторий с GitHub и распакуйте его в удобную папку.

### 3. Установите зависимости

Откройте терминал в папке проекта и выполните команду:

```bash
npm install
```

Если при установке или запуске возникли проблемы с зависимостями, в Windows PowerShell/Linux можно удалить папку `node_modules` и установить зависимости заново:

```powershell
Remove-Item -Recurse -Force node_modules
npm install
```

### 4. Запустите панель

Выполните команду:

```bash
node server.js
```

После запуска в терминале появится информация о работе панели. Если для доступа к ней нужен адрес, используйте адрес и порт, указанные в терминале.

**Важно:** не закрывайте терминал, пока панель работает. Для остановки нажмите `Ctrl + C`.

## ⚙️ Подключение серверов

Для работы панели необходимо запустить её на сервере, где находятся файлы, с которыми вы хотите работать.

### 🖥️ Если у вас один сервер

Просто запустите панель на том сервере, где находятся ваши проекты и файлы.

### 🌐 Если у вас два или более серверов

1. Запустите панель на каждом сервере, которым хотите управлять.
2. Откройте категорию **«Серверы»** в панели управления.
3. Подключите остальные серверы, следуя инструкциям в интерфейсе.
4. Все необходимые данные для подключения отображаются в терминале соответствующего сервера.

После подключения вы сможете управлять проектами на разных серверах через предусмотренную системой интеграцию.

## 💡 Возможности проекта
